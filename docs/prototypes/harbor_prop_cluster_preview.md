# Harbor Prop Cluster Preview

A self-contained prop cluster for visual review of harbor storytelling details.

## Included
- Slatted wooden crate.
- Low-poly barrel with independent iron hoops and lid.
- Mooring bollard with rope coil.
- Drain grate.
- Broken wet-surface highlight strips.

## Purpose
Test prop scale, material palette, and placement density together. These are procedural placeholders for later replaceable meshes.

## Caveats
Not runtime validated. Check mesh/material behavior and mobile performance in Godot before integrating. This scene is isolated from gameplay.
